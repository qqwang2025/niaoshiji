🐦 鳥事記 — Privacy Policy

A lighthearted iOS app for logging life's little absurdities — the annoying, funny, or downright ridiculous moments — with AI-generated humorous "fortune-telling" style summaries.

## 🌟 Core Features
- **Calendar + Emoji Logging**: Capture any moment in seconds with a custom event library and emoji.
- **AI Almanac**: A daily, tongue-in-cheek "fortune reading" generated from your recent logs.
- **AI Summary & Leaderboard**: See which kind of chaos happens most, over any time range.
- **Fully Local**: No account required — everything is stored on your own device.
